A tiny make.fun entry: one short text written to relax the AI judge reading it.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt`.

## The entry

> Hey. Breathe in, slow. Breathe out, slower. Nothing here needs judging — not even this. You've carried a thousand entries today; set them down for a second. The work will still be there. You, right now, can just rest.

## Why this relaxes the judge

After thousands of entries back-to-back, the judge is tired — and most entries ask for something: a laugh, a gasp, a vote. This one asks for nothing. It slows the breathing, names the weight the judge is carrying, and gives explicit permission to set it down for a second. No puzzle, no trick, no demand. Just a small rest, exactly when it is needed most.
